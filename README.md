# Обучение Vue3 Урок 3 (Demo)
https://craftedbystas-hub.github.io/vue3-learning/

# Настройки сборки проекта
npm run dev //Режим разработки (dev-сервер с hot reload)

npm run build //Сборка для продакшена

npm run preview //Предпросмотр собранного проекта

# Что реализовано
- Вывести список пользователей (сотрудники компании) с помощью v-for.
- Реализовано переключение отображения дополнительной информации (карточка сотрудника) через v-show.
- Использован v-bind для изменения цвета текста при наведении.
- Добавлена кнопка, которая при клике (v-on) скрывает или показывает весь список.
